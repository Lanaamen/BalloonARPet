# BalloonARPet (AR Pet Game)

BalloonARPet is an augmented reality (AR) pet game developed in Unity using C#. The player interacts with a virtual pet balloon in AR. 
The project emphasizes immersive interaction and visual effects in mixed reality environments.

## Gameplay
- Place and view the pet-balloon in real-world surroundings using AR
- Interact with the pet through controller input
- Visual feedback and responses

## Features
- Built with Unity, using C#
- AR-enabled experience (AR Foundation)
- Interactive pet animations and visual effects

## Technologies
-	Unity
-	C#
-	AR SDK (AR Foundation)
